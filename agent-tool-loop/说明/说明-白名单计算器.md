# 说明 - 白名单计算器

> 项目：agent-tool-loop · 读者：完全不懂技术的第一次求职者 · 写作日期：2026-10-11

## ① 一句话是什么

只认预先批准的算式写法，别的写法一律拒绝的计算器。

## ② 为什么需要它

计算器工具收到的算式来自助手输出，属于「外部输入」——不可信。如果直接把它当程序代码执行，别有用心的人可以在算式里夹带恶意代码：删文件、读秘密都有可能。

白名单（Whitelist，预先列出的「只允许这些」的清单）是应对思路：列出所有安全写法，清单之外的写法直接拒绝。宁可不答，不能出事。

没有它会怎样：等于把「执行任意代码」的后门开给了所有能影响助手输入的人。

## ③ 在我们项目里长什么样

- 代码在 [tools/calc.py](file:///E:/DSHPersonalAI/projects/agent-tool-loop/tools/calc.py)
- 不用 eval（Python 自带的一个函数，会把字符串直接当代码执行，是出名的安全隐患），改用抽象语法树（AST，Abstract Syntax Tree，把一段算式解析成程序能逐项检查的树状结构）：先用标准库把算式解析成树，再逐个节点核对白名单
- 允许的运算：加、减、乘、除、整除、取余、乘方；节点类型只允许数字和上述运算
- 防卡死限制：乘方指数不超过 1000，计算结果绝对值不超过 10 的 15 次方
- 拒绝时返回带原因的失败结果（`{"ok": false, ...}`），错误信息还能回填给助手继续对话
- 测试：[tests/test_calc.py](file:///E:/DSHPersonalAI/projects/agent-tool-loop/tests/test_calc.py) 里有正常算式和多种恶意写法（想调函数、想访问变量的）用例，恶意写法必须全部被拒绝；属全部 70 条测试的一部分

## ④ 面试怎么讲（约 40 秒）

「计算器工具收到的算式来自模型输出，属于外部输入，我坚决不用 eval 直接执行。做法是先用 Python 标准库把算式解析成语法树，然后逐个节点对白名单：只允许数字和几种算术运算，乘方指数和结果大小都有上限，防止有人让程序算一个天文数字把自己卡死。任何不在白名单里的写法——包括想调函数的、想访问变量的——一律拒绝，并返回明确的错误信息。这样工具失败也是安全的失败，错误信息还能回填给模型继续对话。」

## ⑤ 常见误解 / 坑

- **误解**：「黑名单挡住已知的坏写法就够了」。挡不完，花样永远比清单多。白名单反过来：只放行确认安全的写法，剩下的全拒绝。
- **误解**：「乘方无害」。2 的十万次方能让程序卡很久，所以指数设了 1000 上限。
- **我们踩过的坑（设计层面）**：只检查字符串内容不看结构，会被各种变形写法绕过。改成语法树之后，检查的是「运算本身是什么」，字符串上的花样基本失效。

## ⑥ 关联词
